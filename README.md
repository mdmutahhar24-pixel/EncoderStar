## What is EncoderStar?
EncoderStar is a website where you can **Cipher**, **Decipher**, **Encode**, and **Decode** messages. (Before you ask, yes, Ciphering and Encoding are two different things)

## Why would this ever be useful to me?
Couple of things:
- Safety (**DO NOT DEPEND ON ENCODERSTAR FOR SECURITY**)
- Secret messages
- Learning how ciphering, deciphering, ect. works!


## Included:
- Guides Page
- Cipher
  - Atbash
  - Substitution
  - Caesar's
- Decipherer
  - Same as Cipher, but Decipher
- Encoder
  - ASCII
- Decoder
  - Same as Encoder but Decoding
